# Materia ERP 用户故事

> 说明：以下用户故事覆盖全部 P0 场景，并补充关键 P1 场景，供后续设计、数据库、后端和前端实现使用。

### US-001: 管理员新增物料
**角色**：管理员  
**目标**：作为管理员，我希望新增物料主数据，以便后续出入库单据可以正确引用该物料。  
**验收标准**：
- [ ] 可填写物料编码、物料名称、物料类别、规格、单位
- [ ] 可配置是否启用批次管理、是否启用效期管理
- [ ] 物料编码重复时系统阻止保存并提示
- [ ] 保存成功后物料可在列表中查询到

### US-002: 管理员编辑或停用物料
**角色**：管理员  
**目标**：作为管理员，我希望更新或停用物料，以便控制主数据的准确性和可用范围。  
**验收标准**：
- [ ] 可编辑非唯一性字段，如名称、规格、单位、备注
- [ ] 可停用物料，停用后不可用于新单据
- [ ] 历史单据仍可查看已停用物料信息
- [ ] 系统记录最后修改人和修改时间

### US-003: 管理员维护仓库
**角色**：管理员  
**目标**：作为管理员，我希望维护仓库信息，以便库存可以准确归属到不同仓库。  
**验收标准**：
- [ ] 可新增仓库编码、仓库名称、位置、状态
- [ ] 仓库编码必须唯一
- [ ] 停用仓库不可用于新出入库单
- [ ] 仓库列表支持查询与筛选

### US-004: 操作员提交采购入库申请
**角色**：操作员  
**目标**：作为操作员，我希望能提交采购入库申请，以便将采购物料录入系统。  
**验收标准**：
- [ ] 可选择入库类型为采购入库
- [ ] 必须填写物料编码、批号、数量、仓库
- [ ] 对效期物料必须填写生产日期和有效期至
- [ ] 提交后状态变为“待审核”

### US-005: 操作员提交生产入库申请
**角色**：操作员  
**目标**：作为操作员，我希望提交生产入库申请，以便将中间体或成品登记入库。  
**验收标准**：
- [ ] 可选择入库类型为生产入库
- [ ] 必须填写物料、批号、数量、仓库
- [ ] 可填写来源工序或备注信息
- [ ] 提交后可在待审核列表中被审核员看到

### US-006: 操作员提交退货入库申请
**角色**：操作员  
**目标**：作为操作员，我希望登记退货入库，以便恢复退回物料库存。  
**验收标准**：
- [ ] 可选择入库类型为退货入库
- [ ] 必填字段完整校验通过后才能提交
- [ ] 提交后状态为“待审核”
- [ ] 单据详情中可查看申请人和申请时间

### US-007: 审核员审批入库申请
**角色**：审核员  
**目标**：作为审核员，我希望审批入库单，以便只有审核通过的物料才能正式进入库存。  
**验收标准**：
- [ ] 可查看待审核入库单列表
- [ ] 可执行“通过”或“驳回”操作
- [ ] 驳回时必须填写理由
- [ ] 审核通过后库存自动增加

### US-008: 操作员提交生产领料出库申请
**角色**：操作员  
**目标**：作为操作员，我希望提交生产领料申请，以便从库存中领用生产所需物料。  
**验收标准**：
- [ ] 可选择出库类型为生产领料
- [ ] 必须填写物料编码、批号、数量、仓库、用途/去向
- [ ] 提交后状态变为“待审核”
- [ ] 申请记录可在我的单据列表中查看

### US-009: 操作员提交报废出库申请
**角色**：操作员  
**目标**：作为操作员，我希望提交报废出库申请，以便合规地扣减不可再使用的库存。  
**验收标准**：
- [ ] 可选择出库类型为报废出库
- [ ] 必须填写报废原因
- [ ] 提交后进入待审核状态
- [ ] 驳回后可查看驳回原因

### US-010: 操作员提交调拨出库申请
**角色**：操作员  
**目标**：作为操作员，我希望提交调拨出库申请，以便将库存从当前仓库移出到指定去向。  
**验收标准**：
- [ ] 可选择出库类型为调拨出库
- [ ] 必须填写源仓库、物料、批号、数量和去向
- [ ] 提交后进入待审核状态
- [ ] 审批前不实际扣减库存

### US-011: 审核员审批出库申请
**角色**：审核员  
**目标**：作为审核员，我希望审批出库单，以便系统只对合规出库申请执行库存扣减。  
**验收标准**：
- [ ] 可查看待审核出库单列表
- [ ] 审核通过前系统再次校验库存可用量
- [ ] 审核通过后库存自动扣减
- [ ] 驳回时必须填写理由

### US-012: 系统拦截负库存
**角色**：审核员  
**目标**：作为审核员，我希望系统自动阻止库存不足的出库单生效，以便避免负库存。  
**验收标准**：
- [ ] 当出库数量大于可用库存时，系统拒绝执行
- [ ] 页面明确提示“库存不足”
- [ ] 被拒绝的出库单不会扣减库存
- [ ] 审核员可重新处理或驳回该单据

### US-013: 系统锁定过期物料出库
**角色**：审核员  
**目标**：作为审核员，我希望系统自动阻止过期物料出库，以便避免误用失效物料。  
**验收标准**：
- [ ] 系统识别有效期已过的库存记录
- [ ] 过期库存无法通过出库审批
- [ ] 页面提示阻止原因是“物料已过期”
- [ ] 非过期库存不受影响

### US-014: 用户查询实时库存
**角色**：操作员  
**目标**：作为用户，我希望按物料、批号、仓库查看实时库存，以便快速判断可用情况。  
**验收标准**：
- [ ] 可按物料编码、名称、批号、仓库筛选
- [ ] 列表展示可用数量、单位、批号、仓库、有效期
- [ ] 可区分临期、过期、正常状态
- [ ] 数据来源为当前实时库存而非手工汇总

### US-015: 用户查看库存收发明细
**角色**：操作员  
**目标**：作为用户，我希望查看某条库存记录的历史收发明细，以便确认库存变化来源。  
**验收标准**：
- [ ] 可从库存详情进入历史明细
- [ ] 明细展示入库/出库方向、数量、时间、来源单据
- [ ] 可查看申请人与审核人
- [ ] 明细顺序按时间倒序展示

### US-016: 管理员分配角色权限
**角色**：管理员  
**目标**：作为管理员，我希望给用户分配管理员、审核员或操作员角色，以便控制其系统权限。  
**验收标准**：
- [ ] 可新建用户并分配单一角色
- [ ] 不同角色登录后看到的菜单和按钮不同
- [ ] 操作员无审批权限
- [ ] 审核员无物料主数据编辑权限

### US-017: 成品逆向追溯原料批次
**角色**：审核员  
**目标**：作为审核员，我希望从成品批号逆向追溯到原料批次，以便支持问题排查与合规审计。  
**验收标准**：
- [ ] 输入成品批号后可查看对应原料和中间体批次
- [ ] 展示关联单据号、数量和时间
- [ ] 可区分直接上游和间接上游
- [ ] 结果支持按时间顺序浏览

### US-018: 原料正向追踪去向
**角色**：管理员  
**目标**：作为管理员，我希望从原料批号正向查看其流向的中间体和成品，以便定位影响范围。  
**验收标准**：
- [ ] 输入原料批号可查看被哪些批次使用
- [ ] 展示对应物料、批号、数量、单据号
- [ ] 可继续点开下游批次详情
- [ ] 查询结果不遗漏跨多层级关系

### US-019: 用户查看审批记录
**角色**：操作员  
**目标**：作为操作员，我希望查看单据审批记录，以便了解单据状态和原因。  
**验收标准**：
- [ ] 单据详情展示申请人、申请时间、审核人、审核时间、审核结果
- [ ] 驳回单可看到驳回理由
- [ ] 审批通过单可看到生效时间
- [ ] 不同角色看到的信息口径一致

### US-020: 操作员发起盘点任务
**角色**：操作员  
**目标**：作为操作员，我希望发起盘点任务并录入实盘结果，以便发现库存差异。  
**验收标准**：
- [ ] 可按仓库或物料范围创建盘点任务
- [ ] 可录入系统数量与实盘数量对比
- [ ] 系统自动生成差异数量
- [ ] 盘点调整不会直接生效，需进入审批流程

### US-021: 审核员审批盘点调整
**角色**：审核员  
**目标**：作为审核员，我希望审批盘点差异调整，以便库存修正有审计依据。  
**验收标准**：
- [ ] 可查看待审核的盘点调整记录
- [ ] 可通过或驳回调整
- [ ] 通过后库存按差异更新
- [ ] 调整记录保留申请人与审核人信息

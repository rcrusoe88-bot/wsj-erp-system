# Materia ERP 物料管理系统 — 业务概要

> 本文件由产品负责人提供，作为 PO Agent 的唯一业务输入源。

---

## 1. 系统定位

mRNA/LNP 生产过程中的物料全生命周期管理系统（MVP 阶段）。

### 管理范围

| 物料大类   | 典型物料举例                                   |
| ---------- | ---------------------------------------------- |
| 原辅料     | 质粒模板、T7 RNA 聚合酶、NTPs、Cap 类似物      |
| 脂质原料   | MC3/SM-102、DSPC、胆固醇、DMG-PEG2000          |
| 中间体     | mRNA 粗品、mRNA 纯品                           |
| 成品       | LNP 成品、冻干 LNP                             |
| 实验耗材   | 移液枪头、离心管、滤膜、色谱柱                  |
| 仪器设备   | IVT 反应器、切向流超滤系统、微流控混合仪、冻干机 |

---

## 2. 核心业务规则

### 2.1 物料编码

- **规则**：手动填写，无固定编码格式
- **唯一性**：系统层面强制唯一，不允许重复编码

### 2.2 批次管理

- 每批物料拥有**独立批号**
- 库存以 `物料 + 批号 + 仓库` 为最小管理单元
- 需支持**批次追溯**（从成品追溯到原料批次）

### 2.3 效期管理

- 部分物料有保质期（如酶、脂质），需记录**生产日期**和**有效期**
- 效期≤30 天时系统预警
- 过期物料自动锁定，不允许出库

### 2.4 库存规则

- **不允许负库存**：出库数量 > 可用库存时，系统拒绝操作
- 库存余额实时更新

### 2.5 出入库流程

```
操作员发起 → 审核员审批（一级） → 系统执行库存变更
```

- **入库类型**：采购入库、生产入库（中间体/成品）、退货入库
- **出库类型**：生产领料、报废出库、调拨出库
- 入库和出库均需要**一位审核员**审批后才能生效
- 审核员可**通过**或**驳回**（需填写驳回理由）

### 2.6 盘点

- 支持手动发起盘点任务
- 盘点结果与系统库存比对，生成差异报告
- 盘点调整需走审批流程

## 3. 角色与权限

| 角色     | 权限范围                                                                 |
| -------- | ------------------------------------------------------------------------ |
| 管理员   | 物料主数据 CRUD、仓库管理、用户管理、系统设置、查看所有报表              |
| 审核员   | 审核/驳回 入库单和出库单；查看待审核列表；无法编辑物料信息               |
| 操作员   | 发起入库/出库申请、执行盘点、查看自己的操作记录；无法审批，无法改物料信息 |

## 5. MVP 范围定义

### P0（必须有）

- 物料主数据管理（增删改查）
- 入库全流程（操作员提交 → 审核员审批 → 库存增加）
- 出库全流程（操作员提交 → 审核员审批 → 库存扣减）
- 实时库存查询（按物料 / 批次 / 仓库）
- 三角色 RBAC 权限控制
- 批次追溯（正向：原料 → 成品；逆向：成品 → 原料）

### P1（尽快有）

- 效期预警与过期锁定
- 库存盘点
- 操作日志 / 审计追踪

### P2（后续迭代）

- 报表中心（库存日报、收发存月报、呆滞料分析）
- 仪器设备台账与校准管理
- 多仓库调拨
- 与外部系统集成（LIMS、QMS）

---

## 6. 部署要求

- MVP 阶段：单机部署即可，Docker Compose 优先
- 目标用户：10 人以内小团队
- 数据安全：物料信息为商业机密，需基本的认证和日志

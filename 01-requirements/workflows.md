# Materia ERP 业务流程图

## 1. 入库全流程（含审批）

```mermaid
flowchart TD
    A[操作员新建入库单] --> B[填写入库类型/物料/批号/数量/仓库]
    B --> C{字段是否完整}
    C -- 否 --> B1[提示必填项并返回编辑]
    C -- 是 --> D[提交入库申请]
    D --> E[单据状态: 待审核]
    E --> F[审核员查看待审核入库单]
    F --> G{审核结果}
    G -- 驳回 --> H[填写驳回理由]
    H --> I[单据状态: 已驳回]
    G -- 通过 --> J[系统执行入库事务]
    J --> K[增加对应物料+批号+仓库库存]
    K --> L[写入库存流水]
    L --> M[记录审批记录]
    M --> N[单据状态: 已通过]
```

## 2. 出库全流程（含审批、库存校验）

```mermaid
flowchart TD
    A[操作员新建出库单] --> B[填写出库类型/物料/批号/数量/仓库/用途]
    B --> C{字段是否完整}
    C -- 否 --> C1[提示必填项并返回编辑]
    C -- 是 --> D[提交出库申请]
    D --> E[单据状态: 待审核]
    E --> F[审核员查看待审核出库单]
    F --> G{审核结果}
    G -- 驳回 --> H[填写驳回理由]
    H --> I[单据状态: 已驳回]
    G -- 通过 --> J[系统锁定目标库存记录]
    J --> K{库存是否充足}
    K -- 否 --> K1[提示库存不足并拒绝执行]
    K1 --> K2[单据保持待处理或转驳回]
    K -- 是 --> L{物料是否过期}
    L -- 是 --> L1[提示物料过期并拒绝执行]
    L1 --> L2[单据保持待处理或转驳回]
    L -- 否 --> M[系统执行出库事务]
    M --> N[扣减对应物料+批号+仓库库存]
    N --> O[写入库存流水]
    O --> P[记录审批记录]
    P --> Q[单据状态: 已通过]
```

## 3. 盘点流程

```mermaid
flowchart TD
    A[操作员发起盘点任务] --> B[选择仓库或物料范围]
    B --> C[系统生成待盘点清单]
    C --> D[操作员录入实盘数量]
    D --> E[系统计算差异]
    E --> F{是否存在差异}
    F -- 否 --> G[盘点完成并归档]
    F -- 是 --> H[提交盘点调整申请]
    H --> I[审核员查看盘点差异]
    I --> J{审核结果}
    J -- 驳回 --> K[记录驳回原因]
    K --> L[盘点任务状态: 已驳回]
    J -- 通过 --> M[系统执行库存调整事务]
    M --> N[写入库存流水]
    N --> O[记录审批记录]
    O --> P[盘点任务状态: 已通过]
```

## 4. 批次追溯关系

```mermaid
flowchart LR
    A[原料批次] --> B[生产领料出库单]
    B --> C[中间体批次]
    C --> D[再次生产领料出库单]
    D --> E[成品批次]

    E -.逆向追溯.-> C
    C -.逆向追溯.-> A
    A -.正向追踪.-> C
    C -.正向追踪.-> E
```

## 5. 追溯数据记录原则

1. 生产领料时记录上游批次消耗关系。  
2. 生产入库时记录下游批次生成结果。  
3. 同一成品批次可关联多个原料批次。  
4. 查询追溯链时，需同时返回物料、批号、数量、来源单据和时间。

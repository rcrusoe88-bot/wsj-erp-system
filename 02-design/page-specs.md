# Materia ERP 阶段 2 页面规格

## 1. 文档目标

本文档基于 `C:\tmp\materia-erp-ui-reclone\02-design\page-map.md`，把阶段 2 已确认范围内的页面规格写清楚，供后续原型和前端实现使用。

本文档只定义页面层面的目标、信息结构、按钮、规则和状态，不展开接口、数据库和真实交互实现。

## 2. 通用页面约束

### 2.1 角色权限边界
- 管理员：可进入全部页面；可维护物料和仓库主数据；可查看全局业务数据；仍不提供绕过审批直接改库存的入口。
- 审核员：可进入工作台、审批中心、入库申请列表/详情、出库申请列表/详情、实时库存、批次追溯、临期/过期预警、盘点任务；查看审批所需范围内的数据；不可进入物料表单页、仓库表单页等主数据维护页面。
- 操作员：可进入工作台、入库申请列表/表单/详情、出库申请列表/表单/详情、实时库存、批次追溯、盘点任务；默认只查看与自己相关的单据、库存和记录；不可进入审批中心；不可维护物料和仓库主数据。

### 2.2 状态口径
- 草稿：`draft`
- 待审核：`pending_review`
- 已通过：`approved`
- 已驳回：`rejected`
- 盘点无差异完成：`completed`

### 2.3 统一业务规则
- 所有出入库明细必须使用 `lot_number` 作为业务批号字段口径。
- 所有入库、出库、盘点调整都走“提交 -> 审批 -> 生效”闭环。
- 驳回时必须填写理由。
- 对启用效期管理的物料，必须填写生产日期和有效期至。
- 调拨出库只保留“调拨出库登记”，只录入去向，不出现目标仓签收字段，不出现目标仓入库确认字段。
- 已过期物料不可出库；临期定义为效期剩余天数小于等于 30 天。

## 3. 页面规格

## 3.1 登录页（P0）
### 目标用户
管理员 / 审核员 / 操作员

### 目标
让用户使用用户名和密码进入与角色匹配的系统入口。

### 核心字段或区块
- 用户名
- 密码
- 登录按钮区
- 登录失败提示区
- 停用用户提示区

### 主按钮
- 登录

### 关键规则
- 用户名和密码为必填。
- 登录成功后按角色进入默认入口：管理员进入工作台，审核员优先进入工作台待办区或审批相关入口，操作员优先进入工作台发起区或“我的单据”视图。
- 停用用户不可登录。
- 登录失败时给出明确提示，不暴露额外系统信息。

### 状态
- Loading：提交登录中，按钮禁用并显示加载状态。
- Error：用户名或密码错误、账号停用、系统异常。
- Empty：不适用。

## 3.2 工作台（P0）
### 目标用户
管理员 / 审核员 / 操作员

### 目标
作为登录后的工作台/首页型入口页，给不同角色提供进入已定义页面的第一入口，并集中展示待办与风险提醒。

### 核心字段或区块
- 顶部欢迎区
- 快捷入口区
- 待办卡片区
- 风险提醒区
- 最近单据区

### 主按钮
- 新建入库申请
- 新建出库申请
- 进入审批中心（仅管理员/审核员可见）
- 查看实时库存
- 查看批次追溯

### 关键规则
- 管理员看到全局概览、待审核数量、库存预警、最近业务单据。
- 审核员优先看到审批所需范围内的待审核入库、待审核出库、待处理盘点调整。
- 操作员优先看到“我的待审核单据”“我的已驳回单据”“快捷发起”，不展示与自己无关的全量单据或库存汇总。
- 操作员不显示审批操作入口。
- 本页作为导航入口/首页，不扩展为独立复杂业务模块。

### 状态
- Loading：加载待办、统计卡片、最近单据。
- Error：工作台聚合数据加载失败时展示错误提示和重试入口。
- Empty：无待办、无最近单据时展示空状态和快捷发起按钮。

## 3.3 物料列表页（P0）
### 目标用户
管理员

### 目标
维护和查询物料主数据，确保后续入库、出库、库存、追溯都能正确引用物料。

### 核心字段或区块
- 筛选区：物料编码、物料名称、物料类别、启用状态、是否批次管理、是否效期管理
- 列表区：物料编码、物料名称、物料类别、规格、单位、批次管理、效期管理、存储条件、状态
- 操作列：查看/编辑/停用

### 主按钮
- 新建物料
- 查询
- 重置筛选
- 编辑
- 停用

### 关键规则
- 只有管理员可进入和操作本页。
- 物料编码需保持唯一。
- 列表中的“是否批次管理”“是否效期管理”必须与阶段 1 口径一致。
- 停用后不建议再用于新单据选择，但历史单据仍可查看。

### 状态
- Loading：列表和筛选结果加载中。
- Error：查询失败、列表加载失败。
- Empty：无匹配物料时展示空状态和“新建物料”入口。

## 3.7 入库申请列表页（P0）
### 目标用户
管理员 / 审核员 / 操作员

### 目标
查看入库申请，按角色进入新建、详情和后续审批处理。

### 核心字段或区块
- 筛选区：入库单号、入库类型、状态、申请人、仓库、提交时间
- 列表区：入库单号、入库类型、仓库、申请人、提交时间、状态
- 视图区：全部单据 / 我的单据 / 待审核（管理员、审核员）

### 主按钮
- 新建入库申请（管理员/操作员可见）
- 查看详情
- 去审批（管理员/审核员在待审核记录上可见）

### 关键规则
- 操作员默认优先看到“我的单据”，不默认展示与自己无关的入库申请。
- 审核员查看审批所需范围内的入库申请，并只处理待审核记录。
- 管理员可查看全部入库申请。
- 列表状态口径统一使用 `draft` / `pending_review` / `approved` / `rejected` 对应中文展示。
- 审批动作不在本页直接完成时，也要能跳转到详情页或审批中心。

### 状态
- Loading：列表和筛选加载中。
- Error：查询失败。
- Empty：无匹配单据时展示空状态；操作员场景下可引导去新建入库申请。

## 3.8 入库申请表单页（P0）
### 目标用户
管理员 / 操作员

### 目标
发起采购入库、生产入库、退货入库申请。

### 核心字段或区块
- 单头信息：入库类型、仓库、来源单号、备注
- 明细区：物料、`lot_number`、数量、单位、生产日期、有效期至、备注
- 生产入库扩展区：上游原料/中间体批号、消耗数量

### 主按钮
- 保存草稿
- 提交申请
- 取消
- 新增明细行
- 删除明细行

### 关键规则
- 只有管理员和操作员可发起。
- 入库类型支持采购入库、生产入库、退货入库。
- 明细至少包含物料、`lot_number`、数量、单位。
- 对启用效期管理的物料，必须填写生产日期和有效期至。
- 生产入库时必须录入上游原料/中间体批号及消耗数量，用于后续批次追溯。
- 提交后状态变为待审核。
- 表单不提供审批按钮。

### 状态
- Loading：加载物料、仓库选项和编辑中的草稿数据。
- Error：保存失败、提交失败、主数据加载失败。
- Empty：新建态明细为空时展示“新增明细行”引导。

## 3.9 入库申请详情页（P0）
### 目标用户
管理员 / 审核员 / 操作员

### 目标
查看单张入库申请的完整信息、审批记录和结果状态。

### 核心字段或区块
- 单头信息：入库单号、入库类型、仓库、申请人、申请时间、状态、备注
- 明细区：物料、`lot_number`、数量、单位、生产日期、有效期至
- 追溯关联区：上游原料/中间体批号及消耗数量（生产入库时显示）
- 审批记录区：审核人、审核时间、审核结果、驳回理由、生效时间

### 主按钮
- 返回列表
- 编辑草稿（仅草稿或已驳回且允许重提时可见）
- 再次提交（已驳回后重提时可见）
- 通过（管理员/审核员在待审核时可见）
- 驳回（管理员/审核员在待审核时可见）

### 关键规则
- 驳回操作必须弹出理由输入区，理由必填。
- 审核员只能审核，不能修改业务字段。
- 操作员只能查看详情和审批结果，不能审批。
- 已通过单据可查看生效时间。
- 已驳回单据必须显示驳回理由。

### 状态
- Loading：详情、明细、审批记录加载中。
- Error：详情加载失败。
- Empty：审批记录为空时仅出现在草稿态，可展示“尚未提交审批”。

### 核心字段或区块
- 筛选区：物料编码、物料名称、`lot_number`、仓库、效期状态
- 列表区：物料编码、物料名称、仓库、`lot_number`、账面数量、可用数量、锁定数量、单位、生产日期、有效期至、效期状态
- 快捷查看区：详情入口、追溯入口

### 主按钮
- 查询
- 重置筛选
- 查看详情
- 查看追溯

### 关键规则
- 列表必须能区分正常、临期、过期三种效期状态。
- 已过期记录需明显高亮，并与不可出库口径保持一致。
- 本页只做查询与下钻，不提供直接改库存按钮。
- 操作员默认只查看与自己相关的库存记录。
- 审核员可查看与待审核单据、已审核记录、库存校验直接相关的库存信息，不查看与审批核对无关的全量库存数据。
- 管理员查看全量库存数据。

### 状态
- Loading：库存列表和筛选结果加载中。
- Error：库存查询失败。
- Empty：无匹配库存记录时展示空状态和筛选建议。

## 3.15 库存详情抽屉 / 明细区（P0）
### 目标用户
管理员 / 审核员 / 操作员

### 目标
查看单条库存记录的完整信息和库存流水，解释库存变化来源。

### 核心字段或区块
- 库存摘要区：物料、仓库、`lot_number`、账面数量、可用数量、锁定数量、单位、生产日期、有效期至、效期状态
- 库存流水区：方向、数量、时间、来源单据、申请人、审核人
- 关联入口区：查看来源单据详情、查看批次追溯

### 主按钮
- 查看来源单据
- 查看批次追溯
- 关闭抽屉

### 关键规则
- 库存流水按时间倒序展示。
- 每条流水要能标明入库/出库方向和来源单据。
- 详情区只展示历史，不提供调整库存动作。
- 操作员默认只查看与自己相关的库存记录及流水。
- 审核员可查看与待审核单据、已审核记录、库存校验、追溯核对直接相关的库存记录及流水，不查看与审批核对无关的全量库存流水。
- 管理员查看全量库存记录及流水。
- 对应记录若为过期状态，应在摘要区显著标识。

### 状态
- Loading：库存摘要和库存流水加载中。
- Error：详情加载失败。
- Empty：库存流水为空时展示“暂无库存流水”。

## 3.16 批次追溯页（P0）
### 目标用户
管理员 / 审核员 / 操作员

### 目标
支持从成品批号逆向追溯到原料批次，也支持从原料批号正向追踪去向。

### 核心字段或区块
- 查询区：查询方向（逆向追溯 / 正向追踪）、物料、`lot_number`
- 结果区：上游/下游物料、上游/下游 `lot_number`、数量、来源单据、时间、层级关系
- 关系展示区：列表或树状关系

### 主按钮
- 开始查询
- 重置
- 查看关联单据详情
- 查看下游批次详情

### 关键规则
- 查询口径统一使用 `lot_number`。
- 逆向追溯时，重点展示成品批号对应的原料和中间体批次。
- 正向追踪时，重点展示原料批号被哪些中间体或成品批次使用。
- 操作员默认仅查看与自己相关的追溯关系，或自己发起业务直接关联到的批次关系，不查看与自己无关的全链路全量追溯结果。
- 审核员可查看与待审核单据、已审核记录、库存校验、追溯核对直接相关的批次关系，不查看与审批核对无关的全链路全量追溯数据。
- 结果至少展示物料、批号、数量、来源单据和时间。
- 查询结果不遗漏当前可见范围内的多层级关系。

### 状态
- Loading：追溯链查询中。
- Error：查询失败、关系加载失败。
- Empty：无匹配追溯关系时展示空状态并提示检查 `lot_number`。

## 3.17 临期 / 过期预警页（P1）
### 目标用户
管理员 / 审核员

### 目标
集中查看临期和过期库存，支持优先处理风险物料。

### 核心字段或区块
- 标签区：临期 / 过期
- 筛选区：仓库、物料、`lot_number`、效期状态
- 列表区：物料、仓库、`lot_number`、可用数量、生产日期、有效期至、剩余天数、效期状态
- 快捷入口区：查看库存详情、查看批次追溯

### 主按钮
- 查询
- 重置筛选
- 查看库存详情
- 查看批次追溯

### 关键规则
- 临期定义为有效期剩余天数小于等于 30 天。
- 过期记录需与“不可出库”规则一致。
- 操作员不作为本页目标用户。
- 本页以提醒和查询为主，不提供直接改库存按钮。

### 状态
- Loading：预警列表加载中。
- Error：预警数据加载失败。
- Empty：当前无临期或过期记录时展示空状态。

## 3.18 盘点任务页（P1）
### 目标用户
管理员 / 审核员 / 操作员

### 目标
查看和处理盘点任务，覆盖任务列表、盘点录入、差异展示和审批入口。

### 核心字段或区块
- 任务列表区：盘点单号、盘点范围、申请人、提交时间、状态
- 筛选区：盘点单号、仓库、物料范围、状态、申请人
- 任务表单区：仓库或物料范围、盘点说明
- 盘点明细区：物料、仓库、`lot_number`、系统数量、实盘数量、差异数量
- 审批记录区：审核人、审核时间、审核结果、驳回理由

### 主按钮
- 新建盘点任务（管理员/操作员可见）
- 录入实盘数量（管理员/操作员在可编辑状态下可见）
- 提交盘点任务
- 查看详情
- 通过（管理员/审核员在待审核调整时可见）
- 驳回（管理员/审核员在待审核调整时可见）

### 关键规则
- 操作员可发起盘点任务并录入实盘数量。
- 审核员可查看待审核的盘点调整记录并执行通过或驳回。
- 差异数量由系统数量与实盘数量对比得出。
- 有差异时，盘点调整不会直接生效，需进入审批流程。
- 驳回时必须填写理由。
- 无差异任务状态可为已完成；有差异并审批通过后按已通过口径展示。

### 状态
- Loading：任务列表、盘点明细、审批记录加载中。
- Error：任务加载失败、保存失败、提交失败、审批失败。
- Empty：无盘点任务时展示空状态并引导新建任务。

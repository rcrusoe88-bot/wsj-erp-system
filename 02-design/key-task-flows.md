# Materia ERP 阶段 2 关键任务路径

## 1. 文档目标

本文档基于 `02-design/page-map.md` 与 `02-design/page-specs.md`，整理 Materia ERP 阶段 2 原型需要表达的关键任务路径，帮助后续原型页明确：

- 用户从哪里进入
- 每一步看什么、点什么
- 关键分支怎么走
- 审批、驳回、库存校验、追溯查询如何在页面路径上体现

本文档只描述页面路径与页面行为，不展开真实接口、数据库或系统实现。

## 2. 任务路径使用原则

### 2.1 路径表达范围
- 只覆盖当前阶段已定义的 P0 / P1 页面。
- 只表达用户在页面上的任务动作、跳转关系和关键状态。
- 不扩展未进入当前范围的新页面。

### 2.2 角色口径
- 管理员：可走全量路径。
- 审核员：只走审批、核对、查询相关路径。
- 操作员：只走发起、查看、重提、查询相关路径，不进入审批中心。

### 2.3 业务口径
- P0 的入库、出库遵循“提交 -> 审批 -> 生效”。
- P1 的盘点调整在纳入时也遵循同一审批口径，但不属于 P0 完整闭环。
- 驳回必须填写理由。
- 出库审批前必须再次校验库存可用量和效期状态。
- 调拨场景只保留“调拨出库登记”，不形成目标仓入库，不增加目标仓库存，不出现目标仓签收路径，不出现目标仓入库确认路径。
- 追溯统一使用 `lot_number` 作为查询批号字段。

## 3. P0 关键任务路径

## 3.1 登录进入系统

### 目标用户
管理员 / 审核员 / 操作员

### 起点
登录页

### 标准路径
登录页 -> 输入用户名与密码 -> 点击“登录” -> 系统校验账号状态与密码 -> 进入角色默认入口

### 角色分支
- 管理员：进入工作台。
- 审核员：进入工作台待办区或审批相关入口。
- 操作员：进入工作台发起区或“我的单据”视图。

### 异常分支
- 用户名或密码错误：停留登录页 -> 展示错误提示。
- 账号停用：停留登录页 -> 展示停用提示。
- 系统异常：停留登录页 -> 展示系统错误提示。

## 3.2 操作员发起入库申请

### 目标用户
管理员 / 操作员

### 起点
工作台快捷入口 或 入库申请列表页

### 标准路径
工作台 / 入库申请列表页 -> 点击“新建入库申请” -> 进入入库申请表单页 -> 填写单头信息 -> 填写明细 -> 点击“提交申请” -> 状态变为待审核 -> 返回入库申请列表页查看状态

### 明细录入关键点
- 必填：物料、`lot_number`、数量、单位。
- 启用效期管理的物料：必须填写生产日期、有效期至。
- 生产入库：必须填写上游原料 / 中间体批号与消耗数量。

### 页面分支
- 点击“保存草稿”：状态保留为草稿 -> 返回列表或后续继续编辑。
- 草稿详情页 -> 点击“编辑草稿” -> 回到表单继续修改。
- 已驳回详情页 -> 查看驳回理由 -> 点击“再次提交” -> 重新进入待审核。

### 异常分支
- 主数据未加载成功：表单页展示错误提示。
- 缺少必填项：停留表单页，提示补全。
- 生产入库缺少上游批号 / 消耗数量：禁止提交。
- 保存或提交失败：停留当前页并提示失败。

## 3.3 审核员审核入库申请

### 目标用户
管理员 / 审核员

### 起点
工作台待办区 / 审批中心 / 入库申请列表页待审核视图

其中“待审核视图”是列表页内的标签 / 筛选视图，不是新增独立页面。

### 标准路径
工作台待办区 / 审批中心 / 入库申请列表页 -> 打开待审核入库申请 -> 进入入库申请详情页 -> 查看单头、明细、审批记录区 -> 点击“通过” -> 单据状态变为已通过 -> 记录审核人、审核时间、生效时间

### 驳回路径
待审核入库详情页 -> 点击“驳回” -> 弹出理由输入区 -> 填写驳回理由 -> 提交驳回 -> 单据状态变为已驳回 -> 申请人在详情页可查看驳回理由

### 限制规则
- 审核员只能审批，不能修改业务字段。
- 操作员不能走审批路径。
- 驳回理由必填。

## 3.4 操作员发起出库申请

### 目标用户
管理员 / 操作员

### 起点
工作台快捷入口 或 出库申请列表页

### 标准路径
工作台 / 出库申请列表页 -> 点击“新建出库申请” -> 进入出库申请表单页 -> 选择出库类型 -> 填写源仓库、去向 / 用途、明细 -> 点击“提交申请” -> 状态变为待审核 -> 返回出库申请列表页查看状态

### 类型分支
- 生产领料：必须填写去向 / 用途。
- 报废出库：必须填写报废原因，可体现在去向 / 用途或备注。
- 调拨出库：必须填写源仓库、物料、`lot_number`、数量和去向。

### 调拨边界
- 调拨出库路径复用出库申请表单和出库详情页。
- 调拨出库只记录源仓移出申请。
- 审批通过后，只体现源仓库存减少。
- 不形成目标仓入库。
- 不增加目标仓库存。
- 不出现目标仓签收路径。
- 不出现目标仓入库确认路径。

### 页面分支
- 点击“保存草稿”：状态保留为草稿。
- 草稿详情页 -> 点击“编辑草稿” -> 返回表单页继续改。
- 已驳回详情页 -> 查看驳回理由 -> 点击“再次提交” -> 重新进入待审核。

### 异常分支
- 缺少必填字段：禁止提交。
- 主数据加载失败：表单展示错误提示。
- 保存或提交失败：停留当前页并提示失败。

### 提交前提示边界
出库申请表单可展示库存 / 效期参考提示，但最终是否允许通过，以审核员审批前的库存可用量和效期校验为准；审批通过前不实际扣减库存。

## 3.5 审核员审核出库申请

### 目标用户
管理员 / 审核员

### 起点
工作台待办区 / 审批中心 / 出库申请列表页待审核视图

其中“待审核视图”是列表页内的标签 / 筛选视图，不是新增独立页面。

### 标准路径
工作台待办区 / 审批中心 / 出库申请列表页 -> 打开待审核出库申请 -> 进入出库申请详情页 -> 查看单头、明细、审批校验提示区 -> 页面展示库存可用量与效期状态 -> 点击“通过” -> 单据状态变为已通过 -> 记录审核信息与生效时间

### 审批前校验
- 校验库存可用量。
- 校验物料是否已过期。
- 明确展示阻止原因。

### 驳回路径
待审核出库详情页 -> 点击“驳回” -> 弹出理由输入区 -> 填写驳回理由 -> 提交驳回 -> 单据状态变为已驳回

### 异常分支
- 库存不足：停留详情页 -> 明确提示“库存不足” -> 不能通过。
- 物料已过期：停留详情页 -> 明确提示“物料已过期” -> 不能通过。
- 审批提交失败：停留详情页 -> 展示失败提示。

### 限制规则
- 审核员只能审批，不能修改业务字段。
- 调拨出库详情页只展示去向，不展示目标仓签收信息。

## 3.6 审批中心集中处理待审核单据

### 目标用户
管理员 / 审核员

### 起点
工作台快捷入口 / 左侧导航“审批中心”

### 标准路径
工作台 / 左侧导航 -> 进入审批中心 -> 默认停留“待审核”标签 -> 使用筛选区筛选业务类型、单据号、申请人、提交时间 -> 在列表中查看摘要 -> 通过侧边预览或点击“查看详情”进入详情 -> 执行“通过”或“驳回” -> 返回待审核列表继续处理下一条

### 历史查看路径
审批中心 -> 切换到“已审核记录”标签 -> 使用筛选区查询 -> 查看历史审批结果与摘要信息

### 业务覆盖范围
- P0：入库申请、出库申请。
- P1：盘点调整未来接入审批中心；本轮 P0 不形成盘点任务、录入、审批页面闭环。

### 限制规则
- 操作员不可进入审批中心。
- 审批中心不直接修改业务字段。
- 驳回必须填写理由。

## 3.7 查询实时库存并下钻详情

### 目标用户
管理员 / 审核员 / 操作员

### 起点
工作台快捷入口 / 左侧导航“实时库存”

### 标准路径
工作台 / 左侧导航 -> 进入实时库存页 -> 输入筛选条件（物料、`lot_number`、仓库、效期状态）-> 点击“查询” -> 查看库存列表 -> 点击“查看详情” -> 打开库存详情抽屉 / 明细区 -> 查看库存摘要与库存流水

### 下钻分支
- 库存详情抽屉 -> 点击“查看来源单据” -> 跳转对应单据详情页。
- 库存详情抽屉 -> 点击“查看批次追溯” -> 跳转批次追溯页并带入条件。

### 关键观察点
- 列表区区分正常 / 临期 / 过期。
- 过期记录高亮。
- 流水按时间倒序展示。
- 每条流水标明方向、数量、来源单据。

### 限制规则
- 本路径只提供查询和下钻。
- 不提供直接改库存按钮。
- 操作员默认只看与自己相关记录。
- 审核员只看与审批核对直接相关记录。
- 管理员可看全量。

## 3.8 查询批次追溯关系

### 目标用户
管理员 / 审核员 / 操作员

### 起点
工作台快捷入口 / 左侧导航“批次追溯”

### 标准路径
工作台 / 左侧导航 -> 进入批次追溯页 -> 选择查询方向（逆向追溯 / 正向追踪）-> 输入物料与 `lot_number` -> 点击“开始查询” -> 查看结果区与关系展示区 -> 点击“查看关联单据详情”或“查看下游批次详情”

### 逆向追溯路径
批次追溯页 -> 选择“逆向追溯” -> 输入成品批号 -> 查询 -> 展示对应原料 / 中间体批次、数量、来源单据、时间、层级关系

### 正向追踪路径
批次追溯页 -> 选择“正向追踪” -> 输入原料批号 -> 查询 -> 展示该批号影响到的中间体 / 成品批次、数量、来源单据、时间、层级关系

### 结果要求
- 至少展示物料、`lot_number`、数量、来源单据、时间。
- 支持当前可见范围内多层级关系展示。
- 不遗漏当前权限范围内的上下游链路。

### 限制规则
- 操作员默认仅查看与自己相关或自己发起业务直接关联的追溯关系。
- 审核员仅查看与审批核对、库存校验、追溯核对直接相关的追溯关系。
- 管理员查看全量。

## 4. P1 关键任务路径

## 4.1 查询临期 / 过期预警

### 目标用户
管理员 / 审核员

### 起点
左侧导航“临期预警”

### 标准路径
左侧导航 -> 进入临期 / 过期预警页 -> 默认查看临期或过期标签 -> 输入仓库、物料、`lot_number` 等筛选条件 -> 点击“查询” -> 查看风险库存列表 -> 点击“查看库存详情”或“查看批次追溯”

### 关键规则
- 临期定义为剩余天数小于等于 30 天。
- 过期记录需要与不可出库规则一致。
- 本页不提供直接改库存按钮。
- 操作员不进入本页。

## 4.2 发起并处理盘点任务（P1 预留路径，不纳入 P0 首批交付）

### 目标用户
管理员 / 审核员 / 操作员

### P1 边界
盘点任务页属于 P1 增强能力。以下路径只用于后续原型预留和规则口径确认，P0 不形成盘点任务、盘点录入、盘点审批的完整页面闭环。

### 起点
工作台 / 左侧导航“盘点管理”

### 操作员 / 管理员发起路径
盘点任务页 -> 点击“新建盘点任务” -> 填写仓库或物料范围、盘点说明 -> 保存任务 -> 进入任务详情 / 录入态 -> 点击“录入实盘数量” -> 填写实盘数量 -> 系统自动计算差异 -> 点击“提交盘点任务”

### 无差异路径
提交盘点任务 -> 系统判断无差异 -> 状态变为已完成

### 有差异路径
提交盘点任务 -> 系统判断有差异 -> 状态进入待审核调整 -> 审核员 / 管理员进入审批处理

### 审核路径
盘点任务页 / 审批中心 -> 打开待审核盘点调整 -> 查看系统数量、实盘数量、差异数量、审批记录 -> 点击“通过”或“驳回”

### 驳回路径
待审核盘点调整 -> 点击“驳回” -> 填写理由 -> 提交驳回 -> 状态变为已驳回

### 关键规则
- 差异数量由系统数量与实盘数量自动计算。
- 有差异不会直接生效，必须走审批。
- 驳回必须填写理由。
- 审核通过后按已通过口径展示。

## 5. 原型表达建议

## 5.1 页面地图应表达
- 用户从哪个入口进入任务。
- 每个任务经过哪些列表、表单、详情、审批页面。
- 哪些步骤有角色限制。
- 哪些步骤有状态分支。

## 5.2 页面原型应重点突出
- 快捷入口。
- 列表到详情的跳转关系。
- 表单提交与草稿保存分支。
- 审批通过 / 驳回分支。
- 库存不足、物料过期、驳回理由等关键提示。

## 5.3 本阶段不表达
- 真实接口调用顺序。
- 真实数据库写入时机。
- 真实库存计算过程。
- 真实追溯查询算法。
- 调拨目标仓签收闭环。

## 6. 本文档边界说明

- 本文档只服务阶段 2 页面原型和页面评审。
- 本文档中的路径描述是页面行为规格，不代表当前系统已开发完成。
- 若后续进入数据库、后端、前端阶段，应以本路径文档作为页面任务流参考，而不是直接视为技术实现方案。

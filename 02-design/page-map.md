# Materia ERP 阶段 2 页面地图

## 1. 设计阶段目标

本阶段只定义 Materia ERP 的页面结构、入口关系、关键任务路径和页面边界，方便非技术用户先确认“系统应该长什么样、从哪里进入、每个角色能看到什么”。

本阶段明确不做以下内容：

- 不做数据库设计
- 不做后端接口设计或实现
- 不做真实前端功能开发
- 不做真实库存计算、审批执行、追溯查询联动

本阶段的交付目标是页面地图与后续页面原型依据，而不是可运行系统。

## 2. 页面分层原则

- P0 页面：支撑 MVP 核心闭环，优先覆盖登录、主数据、入库、出库、审批、库存、追溯。
- P1 页面：在 P0 基础上补齐临期预警、盘点、审计日志等增强能力。
- P2 内容不进入本阶段设计重点，尤其是完整多仓库调拨闭环继续放在 P2。

## 5. 三类角色入口

以下只说明角色登录后的默认进入页面，以及可进入的模块 / 页面入口；这里不新增页面。未标注的页面为 P0；标注“（P1）”的页面为增强页，不属于本阶段首批交付。

## 5.1 管理员入口
管理员登录后，默认进入首页 / 工作台，并可进入以下模块 / 页面：

- 主数据：物料列表页、物料新建 / 编辑页、仓库列表页、仓库新建 / 编辑页、用户与角色管理页
- 入库管理：入库申请列表页、入库新建页、入库详情页
- 出库管理：出库申请列表页、出库新建页、出库详情页
- 审批中心页
- 实时库存列表页、库存详情 / 收发明细页
- 批次追溯页
- 临期 / 过期预警页（P1）
- 盘点管理：盘点任务列表页、盘点新建 / 录入页、盘点详情页（P1）
- 审计日志页（P1）

管理员可以看到全局导航，但页面设计上仍默认遵守“库存变更要走审批”，不提供绕过审批直接改库存的入口。

## 5.2 审核员入口
审核员登录后，默认优先进入审批中心页或工作台待办区，并可进入以下模块 / 页面：

- 审批中心页
- 入库管理：入库申请列表页、入库详情页
- 出库管理：出库申请列表页、出库详情页
- 实时库存列表页、库存详情 / 收发明细页
- 批次追溯页
- 临期 / 过期预警页（P1）
- 盘点管理：盘点任务列表页、盘点详情页（P1）

审核员不进入物料、仓库、用户角色维护页面。

## 5.3 操作员入口
操作员登录后，默认优先进入入库申请列表页或出库申请列表页的“我的单据”视图，也可从工作台发起区进入新建流程；这里的“我的单据”不是独立页面。

操作员可进入以下模块 / 页面：

- 入库管理：入库申请列表页、入库新建页、入库详情页
- 出库管理：出库申请列表页、出库新建页、出库详情页
- 实时库存列表页、库存详情 / 收发明细页
- 批次追溯页
- 盘点管理：盘点任务列表页、盘点新建 / 录入页、盘点详情页（P1）

操作员不进入审批中心，不进入物料、仓库、用户角色维护页面。

## 6. 页面边界

## 6.1 本阶段页面设计要表达什么

本阶段页面地图和后续原型应重点表达：

- 页面之间怎么跳转
- 每类角色从哪里进入
- 每个模块有哪些核心页面
- 列表、表单、详情、审批之间的关系
- 用户完成核心任务时的大致点击路径

## 6.2 本阶段页面设计不表达什么

本阶段不展开以下内容：

- 不细化系统后台和数据存储怎么做
- 不细化每个页面背后如何传数据、如何校验、如何控制权限
- 不直接产出可点击运行的真实功能页面
- 不在这一阶段执行真实登录、真实审批、真实库存扣减
- 不在这一阶段做真实追溯关系查询

因此，页面中的按钮、状态、提示语在本阶段只是设计占位，不代表功能已经可以直接使用。

## 7. 调拨边界说明

本项目当前推荐边界已经确认：完整调拨闭环继续放在 P2；MVP 与本阶段只保留“调拨出库登记”。

页面设计中必须明确以下边界：

- 出库新建页中保留“调拨出库”类型
- 调拨出库只记录源仓库移出申请
- 调拨出库需要填写源仓库、物料、批号、数量、去向
- 调拨出库提交后进入审批流程
- 审批通过后，业务含义仅为源仓库存扣减
- 本阶段不设计目标仓签收页
- 本阶段不设计目标仓入库确认页
- 本阶段不设计完整多仓流转状态跟踪页

换句话说，本阶段页面地图里可以出现“调拨出库申请”，但不能扩展出“目标仓签收闭环”。

- 操作员：隐藏审批中心、用户角色页面，以及主数据维护入口；盘点管理为 P1

## 9. 推荐用户任务路径

### 9.1 操作员发起入库
登录 -> 工作台或入库管理 -> 新建入库申请 -> 提交 -> 返回入库申请列表查看状态

### 9.2 操作员发起出库
登录 -> 工作台或出库管理 -> 新建出库申请 -> 选择出库类型（生产领料 / 报废出库 / 调拨出库）-> 提交 -> 返回出库申请列表查看状态

### 9.3 审核员处理审批
登录 -> 审批中心 -> 打开待审核单据 -> 查看详情 -> 通过或驳回 -> 返回待审核列表

### 9.4 用户查询库存与追溯
登录 -> 实时库存或批次追溯 -> 输入筛选条件 -> 查看库存详情或追溯关系

## 10. 本页结论

阶段 2 的页面地图只用于确认页面范围、角色入口和任务路径，不代表系统已经进入真实开发或可直接使用。

本阶段设计范围以 P0/P1 页面结构为主，并明确保留以下约束：

- P0 为首批交付范围，P1 为后续增强范围
- 调拨只做调拨出库登记
- 不做目标仓签收页
